# E4 — 單軸控制性介入(scale-only / shape-only / head-only)

## 1. 目的與回應對象

**8VrD-W3(1)**:「三個 failure mode 都是 selected cases 說明,沒有『只動一個軸』的 controlled intervention」——Google Doc 標記為 P0、**最便宜且最 decisive**、無備案必做。這是把「axes are identifiable」從觀察性證據升級為介入性證據的實驗,也是 8VrD 從 4 → 5 的關鍵一擊。

## 2. 可行性結論:**可行,全部實驗中 CP 值最高**

- **成本:~30–45 min /(model, dataset)**;預設 Llama-3.1-8B × {mmlu, triviaqa} ≈ **1–1.5 h**。
- 一次模型載入 + 13 個 config,每個 config 一趟 512-sample forward + d×d 矩陣運算。
- 無取捨必要。唯一的裁剪:單 model(Llama)單一主 dataset(MMLU)+ 一個對照 benchmark(TriviaQA)。
- **Dataset 只用論文的 5 個 benchmark**(wikitext/fineweb 未進論文,一律不用);對照選 TriviaQA 是因為它在 E6 中 |ΔR| 動態範圍最寬([~0.0003, 1.14]),CE 訊號最豐富,對 selectivity 驗證最有利。

## 3. 設計(`exp_e4_interventions.py`)

對**同一個 base model** 注入三族純擾動,全部在 forward 內生效,因此 `|ΔR|` 是真實量測(不是模擬):

| 介入 | 實作 | 理論預期(W=I) |
|---|---|---|
| **scale-only** α∈{0.5,0.8,1.25,2.0} | final RMSNorm 輸出 hook ×α | (Δρ)²=(1−α)²ρ² 隨 α 移動;Ω 不變(cosine 對均勻縮放不變)⇒ shape≈0;head 未動 ⇒ γ=0 |
| **shape-only** θ∈{0.05,0.1,0.2,0.4} rad | 最後 hidden states 右乘 R=expm(θÂ),Â skew-symmetric、‖Â‖₂=1 | R 正交 ⇒ 每 token norm 精確保持 ⇒ scale=0(到數值精度);1−Ω_I 隨 θ 單調上升;γ=0 |
| **head-only** b∈{8,6,4,3} bits | lm_head per-row RTN 量化,backbone 不動 | Z 不變 ⇒ δ=0(精確);只有 γ 上升 |

每個 config 記錄:scale term、shape term、γ、bound B(理論 K)、實測 |ΔR|、`bound_holds`(B ≥ |ΔR| 驗證 Theorem 1)、以及 **sup-residual** `max_i‖z_T,i − z_P,i‖`(給 E5 的 concentration corollary 做數值示例——跨實驗共用)。

**Deliverable 是一張 selectivity matrix**:每族介入下三個 term 相對 control 的最大位移——預期各族只推高自己那一軸、其餘兩軸低幾個數量級。這直接對應 Google Doc 8VrD-W3 草稿:

> Each intervention moves its own term by [XX] while leaving the other two within [XX]% — new Fig./Table [X].

附帶產出:γ vs bits 曲線是「GGUF k-quant 量化 lm_head → head 軸」機制的因果版本(呼應論文 Sec. 5.3 的觀察性 case)。

## 5. 風險與注意

| 風險 | 處理 |
|---|---|
| rotation 對 |ΔR| 的影響過激(大 θ 令 loss 爆炸) | θ 網格從 0.05 rad 起跳;若 0.4 過激只報前三點(單調性已足夠) |
| head_discrepancy_spectral 的大 SVD(4096×128k)拖慢 | 每 config +~1 min,已含在估計;必要時註解掉 spectral 欄(cov 版本才進 bound) |
| scale 介入下 Ω_I 有微小數值漂移 | 預期 <1e-4;selectivity 表以數量級呈現,不受影響 |
| bf16 決定性 | 同機同 batch 下 forward 可重現;CSV 記錄完整 config |

## 6. 結果(2026-07-25 定稿;Llama-3.1-8B × {mmlu, triviaqa})

**結論:axis-identifiability 完整成立。26/26 configs bound holds(13 configs × 2 datasets,含 identity control),每族介入只推高自己那一軸,選擇性 ≥ 2.6×10⁵(五個數量級以上)。**

### 6.1 Selectivity matrix(族內 max |term − control|)

| family | Scale term(mmlu / tqa) | Shape term | γ | 選擇性(own/leak) |
|---|---|---|---|---|
| scale-only(α∈{0.5,0.8,1.25,2.0}) | **1.93e4 / 1.99e4** | 6.9e-2 / 7.5e-2 | 0 / 0 | 2.79e5 / 2.66e5 |
| rotation-only(θ≤0.4 rad) | 1.3e-4 / 6.6e-6 | **7.71e2 / 7.93e2** | 0 / 0 | 5.8e6 / 1.2e8 |
| head-only(RTN 8→3 bit) | 0(精確)| 0(精確)| **5.41e2 / 4.62e2** | ∞(Z 未動,恆等為零)|

head-only 的 scale/shape 是**精確零**(backbone 未動 ⇒ Z_T=Z_P 逐位相同),不是「近似小」——這是設計使然,也是最強的一格。

### 6.2 理論標度律 checksum(term 量的是理論說的那個量)

- **Scale ∝ (α−1)²**:以 α=2.0 為基準,α=0.5/0.8/1.25 預測偏差 **0.00% / 0.00% / 0.04%**(兩個 dataset 相同)。
- **Shape ∝ θ²**:以 θ=0.05 為基準,θ=0.1/0.2/0.4 偏差 **0.30% / 0.51% / 1.03%**(tqa:0.33/0.54/1.06%)。
- **γ vs bits 單調**:10.0 → 40.1 → 209.7 → 541.4(mmlu,8/6/4/3 bit;tqa 10.1 → 40.9 → 191.9 → 461.7);8→6 bit 恰為 ×4.0(≈ RTN 噪聲 2^-b 標度),低 bit 端因 clipping 超線性。
- **B 公式恆等式**:B = K_feat·√(Scale+Shape) + K_pred·γ 逐 row 數值吻合(例:scale_x0.5 181.61 = 181.61;head_3bit 653.15 vs 653.02,浮點 roundtrip 內)。

### 6.3 Bound 驗證與實測傷害

- 26/26 `bound_holds`;identity control B = 0.00(mmlu)/ 0.08(tqa)——bound 在原點無虛胖 slack。
- 介入造成**真實 forward 傷害**:α=0.5 在 tqa |ΔR| = 1.386 nats、3-bit head 在 tqa |ΔR| = 0.415——attribution 是因果的(擾動→軸),不是觀察相關。
- 族內 Spearman(B, |ΔR|):head(mmlu)+1.00;其餘 +0.80。兩類 swap 都有明確定性:
  (a) scale 族:B 對方向盲((α−1)² 對稱),實測 α=0.5(縮小)傷害大於 α=2.0(0.33 vs 0.21 nats mmlu;1.39 vs 0.72 tqa)——bound 仍成立、只是方向資訊不在 bound 裡;tightness/校準是 E6 的 scope,E4 的宣稱是 attribution。
  (b) shape/head 小劑量端的 swap 發生在 |ΔR| ≤ 5e-4 nats 的噪聲地板,無資訊量。

### 6.4 Gauge 注意(與 E1 的 B_N 敘事的關係)

E4 刻意用 **W=I gauge**:rotation 必須被 Shape_I 抓到,這正是 Sec 5.3 axis→action 診斷儀器的工作方式(rotation 改變 head 輸入幾何 → 對應 action = Hessian-aware reconstruction)。E1 的 W_N gauge 會把純旋轉吸收掉——那是**排序**用的 gauge。兩者依 App C.1 同樣 certified,分工不同:診斷用 I、排序用 W_N。Rebuttal 中兩處引用互不衝突。
