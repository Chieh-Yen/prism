# E4 — 單軸控制性介入(scale-only / shape-only / head-only)

## 1. 目的與回應對象

**8VrD-W3(1)**:「三個 failure mode 都是 selected cases 說明,沒有『只動一個軸』的 controlled intervention」——Google Doc 標記為 P0、**最便宜且最 decisive**、無備案必做。這是把「axes are identifiable」從觀察性證據升級為介入性證據的實驗,也是 8VrD 從 4 → 5 的關鍵一擊。

## 2. 可行性結論:**可行,全部實驗中 CP 值最高**

- **成本:~30–45 min /(model, dataset)**;預設 Llama-3.1-8B × {mmlu, wikitext} ≈ **1–1.5 h**。
- 一次模型載入 + 13 個 config,每個 config 一趟 512-sample forward + d×d 矩陣運算。
- 無取捨必要。唯一的裁剪:單 model(Llama)單一主 dataset(MMLU)+ 一個 corpus 對照(wikitext)。

## 3. 設計(`exp_e4_interventions.py`)

對**同一個 base model** 注入三族純擾動,全部在 forward 內生效,因此 `|ΔR|` 是真實量測(不是模擬):

| 介入 | 實作 | 理論預期(W=I) |
|---|---|---|
| **scale-only** α∈{0.5,0.8,1.25,2.0} | final RMSNorm 輸出 hook ×α | (Δρ)²=(1−α)²ρ² 隨 α 移動;Ω 不變(cosine 對均勻縮放不變)⇒ shape≈0;head 未動 ⇒ γ=0 |
| **shape-only** θ∈{0.05,0.1,0.2,0.4} rad | 最後 hidden states 右乘 R=expm(θÂ),Â skew-symmetric、‖Â‖₂=1 | R 正交 ⇒ 每 token norm 精確保持 ⇒ scale=0(到數值精度);1−Ω_I 隨 θ 單調上升;γ=0 |
| **head-only** b∈{8,6,4,3} bits | lm_head per-row RTN 量化,backbone 不動 | Z 不變 ⇒ δ=0(精確);只有 γ 上升 |

每個 config 記錄:scale term、shape term、γ、bound B(理論 K)、實測 |ΔR|、`bound_holds`(B ≥ |ΔR| 驗證 Theorem 1)、以及 **sup-residual** `max_i‖z_T,i − z_P,i‖`(給 E5 的 concentration corollary 做數值示例——跨實驗共用)。

**Deliverable 是一張 selectivity matrix**:每族介入下三個 term 相對 control 的最大位移——預期各族只推高自己那一軸、其餘兩軸低幾個數量級。這直接對應 Google Doc 8VrD-W3 草稿:

> Each intervention moves its own term by [XX] while leaving the other two within [XX]% — new Fig./Table [X].

附帶產出:γ vs bits 曲線是「GGUF k-quant 量化 lm_head → head 軸」機制的因果版本(呼應論文 Sec. 5.3 的觀察性 case)。

## 4. 執行

```bash
bash rebuttal_exp/script_E4.sh                          # mmlu + wikitext
DATASETS=mmlu bash rebuttal_exp/script_E4.sh            # 只跑主表 (~40 min)
```

輸出:`out/E4/interventions_{model}_{dataset}.csv`、`E4_results_{...}.md`(含 selectivity 表)。

## 5. 風險與注意

| 風險 | 處理 |
|---|---|
| rotation 對 |ΔR| 的影響過激(大 θ 令 loss 爆炸) | θ 網格從 0.05 rad 起跳;若 0.4 過激只報前三點(單調性已足夠) |
| head_discrepancy_spectral 的大 SVD(4096×128k)拖慢 | 每 config +~1 min,已含在估計;必要時註解掉 spectral 欄(cov 版本才進 bound) |
| scale 介入下 Ω_I 有微小數值漂移 | 預期 <1e-4;selectivity 表以數量級呈現,不受影響 |
| bf16 決定性 | 同機同 batch 下 forward 可重現;CSV 記錄完整 config |
