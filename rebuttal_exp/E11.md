# E11 — Base vs Instruct:PTQ/frozen-head LoRA 之外的第一個 data point(G3T9-Q1)

## 1. 目的與回應對象

**G3T9-Q1**:「PRISM 可否用在 PTQ 與 frozen-head LoRA 之外(full FT、RLHF)?」

draft 的回答主幹是劃界:分解只需同架構同維度,full FT/RLHF 落在**帶非零 head 項
的一般形式**;代價是 tightness(App. C.3 明文 scope out、App. I 列 future work)。
E11 提供括號裡承諾的 *first data point*:target = base checkpoint、proxy = 同
family 的 instruct checkpoint——這正是「features rotated + heads divergent」的
full-post-training regime,端到端跑一次給數字。

## 2. 可行性結論:**可行,~30–45 min/pair;預設 2 pairs ≈ 1.5 h**

五個 pair 全是論文自己的 family(base 與 instruct 都是論文 target):

| pair | base → instruct |
|---|---|
| llama(預設) | Meta-Llama-3.1-8B → -Instruct |
| qwen(預設) | Qwen3-8B-Base → Qwen3-8B |
| mistral / ministral / qwen25(選配) | v0.3 / 2512 / 2.5-7B 的 base→instruct |

單卡順序載入(先 base 抽完 5 benchmarks 再換 instruct),無雙模型 VRAM 壓力。

## 3. 設計(`exp_e11_base_instruct.py`)

- **協議與論文一致**:512 樣本/benchmark、seed 42、concat token 特徵、
  teacher-forced answer-only CE、W=I;**唯一的新自由度是 H_P = instruct 的
  lm_head(γ>0 引擎啟動)**,head shape 不合直接報錯。
- **兩側餵完全相同的 token ids(base tokenizer、無 chat template)**——
  token-aligned 特徵的必要條件;也與論文用同一組 loader 評 instruct-family
  targets 的作法一致(附錄要註明)。
- 每 (pair, benchmark) 記錄:ρ_T/ρ_P、1−Ω_I、scale/shape term、γ、
  **head share of B**、bound B、實測 |ΔR|、`bound_holds`(Theorem 1 在此
  regime 的端到端驗證)。
- **PTQ context anchor**:同 base family 的 Q4_K_M / Q2_K 的 1−Ω_I(論文 CSV,
  只取 5 benchmarks)——「base→instruct 的幾何漂移比激進量化大幾倍」一句話
  就有依據,正面呼應 C.3 的 tightness 敘事。

## 4. Rebuttal 用法(G3T9-Q1 的 [TBD-E11])

> As a first data point we ran the full decomposition between base and
> instruct checkpoints of the two main-text families (nonzero head term,
> W = I): the bound holds in [N/N] cells; the head term engages (median
> [X]% of B, vs 0% in the frozen-head settings) and 1-Omega is [K]x the
> Q4_K_M level — the decomposition applies mechanically, and what degrades
> is tightness, exactly as App. C.3 anticipates. Validated claims stay
> scoped to PTQ and frozen-head LoRA.

無論數字如何都成立:bound 是定理,`holds` 欄是驗證而非賭注;1−Ω/γ 變大只是
把「tightness caveat」量化,不威脅任何已 scope 的 claim。

## 5. 風險與 fallback

| 風險 | 處理 |
|---|---|
| instruct 在 raw format 下 loss 偏高使 \|ΔR\| 巨大 | 預期內——這正是 drift 大的體現;bound 仍應 hold,B/\|ΔR\| slack 誠實報 |
| 某 pair vocab/head 不匹配 | 腳本直接報錯跳過;五個 pair 皆同 vocab,風險極低 |
| 時間不足 | 跑不完就用 draft 原 else 句(「explicitly future work」);單 pair(llama,~40 min)也足以填 [TBD-E11] |

## 6. 執行

```bash
PAIRS="llama" bash rebuttal_exp/script_E11.sh         # 最省 (~40 min)

```

## 結果(2026-07-25 定稿;詳表 out/E11/E11_results.md)

- **10/10 (pair, benchmark) cells bound holds**——full-post-training regime
  (App C.3 劃界區)end-to-end 驗證,Theorem 1 未破。
- **Head term 啟動命中理論預測**:frozen-head 設定結構性 0% → instruct
  lm_head 換上後 head share median **50%**(35–64%)。
- **校準錨**:instruct-tuning 幾何漂移 1−Ω_I median——llama **0.224 ≈ 同
  family Q2_K(0.225)**;qwen **0.254 = 14× Q2_K(0.018)**。
  「instruction tuning 對特徵幾何的擾動 ≥ 2-bit 量化」。
- **Tightness 如預期鬆掉**(B 380–1615 vs |ΔR| 0.02–0.73,例 llama-arc
  鬆 2.5e4×)——App C.3 預測的現象被觀察到;draft 主動揭露,claims 仍
  scoped to PTQ + frozen-head LoRA。
- 引用位置:G3T9-Q1(only);策略 = 只報 summary 統計不放 per-cell 表,
  避免單格 looseness 被拿出來打。
