## 3. 數學內容

### Theorem 1′(Empirical Unified Risk Bound;重述)

設 reference sample S = {(xᵢ,yᵢ)}ᵢ₌₁ᴺ,R̂_M = (1/N)Σᵢ ℓ(φ_M(xᵢ)H_M, yᵢ)。對任意 W ∈ O(d):

|R̂_T − R̂_P| ≤ B̂ := K_feat·√((ρ̂_T−ρ̂_P)² + 2ρ̂_Tρ̂_P(1−Ω̂_W)) + K_pred·‖Σ̂_P^{1/2}(WH_T−H_P)‖_F

其中所有帶帽量都由 sample 特徵矩陣 Z_T, Z_P 計算(即論文實際計算的量)。

**證明**:與原 Appendix A 逐步相同,把期望換成 empirical mean——triangle inequality 逐樣本成立;Lipschitz 步驟(simplex polarization)是 pointwise 不等式;Jensen 套在 empirical mean 上同樣成立;Prop. 1 的 scale–shape 分解本來就是 finite-sample 的**恆等式**。∎

關鍵句(rebuttal 用):*所有實驗報告的量本來就是 empirical 的,結論不變;診斷用例的目標本來就是固定 reference set 上的 risk gap。*

### Corollary(Population version via concentration)

令 Dᵢ := ℓ(φ_T(xᵢ)H_T,yᵢ) − ℓ(φ_P(xᵢ)H_P,yᵢ),假設 **(A1)** |Dᵢ| ≤ b a.s.。一個顯式充分條件:特徵有界 ‖φ_M(x)‖₂ ≤ C_z 且對齊殘差有界 sup_x‖φ_T(x)−φ_P(x)W‖₂ ≤ D_Z,則

b ≤ K_feat·D_Z + √2·C_z·‖WH_T−H_P‖_op

(第一項:同一 pointwise Lipschitz 論證穿過 hybrid loss;第二項:logit 空間 √2-Lipschitz + ‖z(WH_T−H_P)‖ ≤ ‖z‖‖·‖_op。**三個常數都是 PRISM pipeline 本來就在量的東西**——這是回應裡漂亮的一句。)

由 Hoeffding/McDiarmid(i.i.d.、均值的 bounded differences 2b/N),以機率 ≥ 1−δ:

|R_T − R_P| ≤ B̂ + b·√(2 ln(2/δ) / N)

**Autoregressive 註記**:sequence-level per-sample loss 是該序列 token losses 的平均,仍以 b 為界且跨序列 i.i.d. ⇒ corollary 以 N = 序列數成立(token-level 非獨立,不能拿 token 數當 N——這點寫清楚可以防第二輪追問)。

### 誠實的數值定位(寫進回應,先發制人)

N=512、δ=0.05 ⇒ √(2·ln 40/512) ≈ 0.12;b 由量測值代入(E4 的 sup_residual × K_feat)。concentration 項與 bound 本身的 slack 同數量級——所以**主敘述是 Theorem 1′(empirical、operational),corollary 是形式完備性**。這正對應 8VrD 的原話「restated accordingly, **or** supplemented」:我們兩者都給,並明說哪個是主用途。
