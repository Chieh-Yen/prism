# E8 — Isometry violation vs bit-width(pCi8-W6)

## 1. 目的與回應對象

**pCi8-W6**:App C.2 把 trace/nuclear 相似度在激進量化下的分歧當作「訊號」——
那 isometry 假設本身到底違反了多少?E8 直接量測:**把 alignment family 從
「任意線性映射 A」限縮到「rotation × 單一 scale(O(r) × s)」,殘差付出多少代價**。

## 2. Metric(`exp_e8_isometry.py`,獨立 lite 腳本,重用 E1 的 ZT 快取)

各邊在**自己的 top-r 主成分基底**(rotation-invariant,同 SVCCA 的 PCA→CCA 結構;
r = min(256, n/4, r90),r90 = 90% energy 有效秩守門):

```
iso_gain = 1 − res_lin / res_orth
res_orth = min_{s, W∈O(r)} ‖X − s·Y·W‖    (isometry family)
res_lin  = min_A ‖X − Y·A‖                (任意線性,lstsq)
```

- iso_gain ≈ 0 ⇒ O(r) 限制零代價(near-isometry 成立)。
- `rel_orth < 2%` 的 row 標 `[floor]`(比值 = 小數相除,不可引)。
- **金測**(identity/rotation+noise ≈ 0、anisotropy 判別為正;2026-07-25 修
  searchsorted CUDA device bug 後重驗,1000 組隨機向量驗證修法與原語義等價)。
- 首版 `iso_dev`(E1 內建欄)已作廢(n_tokens < d 病態;勿引)。

## 3. 結果(2026-07-25 定稿;llama,mmlu + squad,r≤256)

| variant | mmlu:rel_orth / iso_gain | squad:rel_orth / iso_gain | mean iso_gain |
|---|---|---|---|
| FP16(dtype 控制組)| 0.037 / **0.084** | 0.013 / 0.044 [floor] | **0.084** |
| Q8_0 | 0.096 / 0.205 | 0.054 / 0.056 | 0.130 |
| Q4_K_M | 0.342 / 0.238 | 0.163 / 0.091 | 0.165 |
| Q2_K | 0.753 / 0.239 | 0.429 / 0.127 | 0.183 |
| NF4 | 0.499 / 0.287 | 0.207 / 0.091 | 0.189 |

三個讀法(rebuttal 敘事的骨架):

1. **控制組校準刻度**:FP16 vs BF16(純 dtype roundtrip)iso_gain = 0.084——
   這是 metric 自身的噪聲水位(無約束 A 殘留的 overfit 優勢,r/n ≈ 0.11–0.21,
   已有 r ≤ n/4 守門)。量化 rows 要對著 0.08 讀,不是對著 0 讀。
2. **O(r) 限制的代價小且隨 bit 單調緩升**:0.084 → 0.130 → 0.165 → 0.183(Q2_K)。
   逐 cell 看,rotation × scale 已拿下**任意線性對齊可達殘差縮減的 71–94%**
   (量化 rows;控制組 92%)。
3. **決定性補刀——線性根本救不了的部分主導低 bit 損傷**:oracle 任意線性對齊後
   的相對殘差:Q8 7.6% → Q4 26% → **Q2_K 57%**(mmlu;squad 5%→15%→38%)。
   在激進量化下,大部分特徵損傷**不是任何線性 gauge 能吸收的**——isometry 對齊後
   的殘差是真實退化,不是 gauge artifact。

**機制彩蛋**:NF4 的 iso_gain(0.287)高於 Q2_K(0.239)但 rel_orth(0.50)介於
Q4/Q2 之間——NF4 的 block-wise absmax 縮放引入 per-channel 各向異性(比 k-quant
更「對角線性」的失真),恰好呼應論文 Sec 5.3 scale 軸 → per-channel outlier
smoothing 的 action mapping。可作旁證,一句即可。

## 4. Caveats(誠實邊界)

- squad 的 r 被 256 上限綁住(涵蓋 77% variance;mmlu r90=107 涵蓋 90%)——
  上限是為 lstsq 條件數;兩個 family 在同一子空間內比,公平。
- iso_gain 是真實各向異性結構的**上界**(A 的 overfit 餘裕);控制組 0.084 正是
  這個餘裕的實測值。
- mmlu 與 squad 的絕對水位差 ~2×(n/r 比 + answer-token 母體不同)——宣稱建立在
  「趨勢 + 小」上,不做跨 benchmark 絕對值比較。
- FP16-squad 在 noise floor(rel 1.3% < 2%),已旗標並從均值剔除。

## 5. Rebuttal 引用(pCi8-W6;✅ 已填)

控制組 0.08 → Q8/Q4/Q2 = 0.13/0.17/0.18(NF4 0.19);71–94% 已被 rotation×scale
拿下;oracle 線性後 Q2_K 仍餘 57%(mmlu)——「divergence is signal」的直接量測版。
